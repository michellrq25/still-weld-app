Guarda las imágenes reales de tus productos en esta carpeta.

Formatos recomendados:
- .jpg, .png o .webp
- Dimensiones cuadradas (ej: 600x600 px o 800x800 px)
- Fondo blanco o transparente para mantener una estética profesional y uniforme.

Para usarlas:
1. Nombra las imágenes de forma descriptiva (ej. 'rogue-es-150i.jpg').
2. Ve al archivo '/public/products.json' y agrega la propiedad "image": "nombre_de_la_imagen.extension" al producto correspondiente.
   Ejemplo:
   {
     "id": 1,
     "name": "Máquina de Soldar Inverter ESAB Rogue ES 150i",
     ...
     "image": "rogue-es-150i.jpg"
   }
